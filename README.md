# 🪨📄✂️ Stone Paper Scissors Game

A simple and interactive **Stone Paper Scissors** game built using **HTML, CSS, and JavaScript**.  
Play against the computer and test your luck while learning core JavaScript logic.

---

## 🎮 Features

- Play **Stone, Paper, or Scissors** against the computer  
- Computer generates a **random choice** every round  
- Instant result display (Win / Lose / Draw)  
- Clean and simple UI  
- Beginner-friendly JavaScript logic
- stores score
    

---

## 🛠️ Technologies Used

- **HTML** – structure of the game  
- **CSS** – styling and layout  
- **JavaScript** – game logic and interactivity
